The main action control; ink-filled primary, one per view.

```jsx
<Button icon="user-plus">Add a relative</Button>
<Button variant="secondary" icon="upload">Upload photo</Button>
```

primary = ink fill; accent = aubergine (use rarely, e.g. Invite); secondary = outlined card; ghost = text-only; danger = destructive. md is 48px tall (default, touch); sm 36px for dense desktop toolbars.
